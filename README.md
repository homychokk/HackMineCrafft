# PrismGlass

**PrismGlass** — Fabric-клиент для Minecraft **1.20.1** с меню в стиле liquid glass, модулями и кастомным UI.

Открытие меню: **Right Shift**

## Установка

1. Установи [Fabric Loader](https://fabricmc.net/use/) для Minecraft 1.20.1
2. Положи в папку `mods`:
   - [Fabric API 0.92.9+1.20.1](https://modrinth.com/mod/fabric-api)
   - `prismglass-1.0.0.jar` из [Releases](../../releases)
3. Запусти игру

## Возможности

- Liquid glass GUI с категориями, настройками и биндами
- Combat: KillAura, AutoCrit, Hitboxes, Velocity
- Movement: Fly, Speed, Scaffold, NoFall, FreeCam (лут сундуков)
- Render: XRay с подсветкой руд, StorageESP, ESP, Tracers, PlayerFX
- Misc: AutoFarm, Nuker, AutoTool
- HUD: Watermark, FPS, ArrayList и др.

## Сборка

```bash
# Java 17+
gradle build
```

Готовый jar: `build/libs/prismglass-1.0.0.jar`
